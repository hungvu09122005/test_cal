# TC-MUL-003: Nhân số âm với số dương

## Requirement ID
FR-CALC-03

## Module / Test type / Technique
Multiplication / Functional / Equivalence Partitioning

## Preconditions
- Trình duyệt đã mở trang https://testsheepnz.github.io/BasicCalculator.html
- Trường Build đang chọn "Prototype"

## Test data
| First number | -6 |
| Second number | 9 |
| Operation | Multiply |

## Test steps
1. Mở trang Basic Calculator
2. Chọn Build là "Prototype"
3. Nhập "-6" vào trường "First number"
4. Nhập "9" vào trường "Second number"
5. Chọn Operation là "Multiply"
6. Bấm nút "Calculate"

## Expected result
- Trường Answer hiển thị giá trị "-54".
- Không có thông báo lỗi.
