# TC-ADD-002: Cộng hai số thực (thập phân) hợp lệ

## Requirement ID
FR-CALC-01

## Module / Test type / Technique
Addition / Functional / Equivalence Partitioning

## Preconditions
- Trình duyệt đã mở trang https://testsheepnz.github.io/BasicCalculator.html
- Trường Build đang chọn "Prototype"

## Test data
| First number | 12.35 |
| Second number | 7.65 |
| Operation | Add |

## Test steps
1. Mở trang Basic Calculator
2. Chọn Build là "Prototype"
3. Nhập "12.35" vào trường "First number"
4. Nhập "7.65" vào trường "Second number"
5. Chọn Operation là "Add"
6. Bấm nút "Calculate"

## Expected result
- Trường Answer hiển thị giá trị "20" (hoặc giá trị chính xác của phép cộng số thực).
- Không có thông báo lỗi.

Not Run / None
